# Web Basics, Phone pe, Roman Urdu mein 📱

**Maqsad:** Claude ka banaya hua code **padh aur samajh** sakna, chhoti changes khud karna, aur client ke sawalon ka jawab de sakna.

**Roz:** 15-20 minute · **Sirf phone** · **Practice:** w3schools.com ka "Try it Yourself" editor (free, sign up ki zaroorat nahi)

**Asool:** har lesson **tumhari apni websites** (Sultan Istanbul, Bella's, BrightSmile...) ke code se hoga.

---

## Hafta 1: HTML (website ka dhancha)
1. HTML kya hai? Tags, heading aur paragraph
2. Links aur buttons (`<a>`): WhatsApp aur call button kaise bante hain
3. Images (`<img>`): photo kaise lagti hai, aur kyun toot jaati hai
4. Lists aur menu items (`<ul>`, `<li>`)
5. Sections aur divs: page ke hisse
6. Forms: naam, phone aur "Book now"
7. **Practice:** apne restaurant ka chhota sa page

## Hafta 2: CSS (website ka rang roop)
8. CSS kya hai? Rang badalna
9. Fonts aur size
10. Spacing: padding aur margin
11. Buttons ko khoobsurat banana
12. Flexbox: cheezein ek line mein lagana
13. Mobile ke liye (media queries), sirf samajhna
14. **Practice:** Lesson 7 wale page ko sajana

## Hafta 3: Asli kaam
15. Sultan Istanbul ka code padhna: kaunsa hissa kya karta hai
16. Menu mein naya item add karna
17. Price aur phone number badalna
18. Rang aur logo badalna
19. Claude ko **achhi instructions** kaise dein (prompting)
20. Galti kaise dhoondein (jab kuch toot jaye)
21. **Practice:** client jaisa ek chhota change khud karna

## Hafta 4: Client aur delivery
22. Website live kaise hoti hai (hosting, domain), samajhna
23. QR code kya hai aur kaise kaam karta hai
24. JavaScript ki sirf pehchaan: WhatsApp order kaise banta hai
25. Client ke 10 aam sawal aur unke jawab
26. **Final:** ek chhota landing page khud badalna aur live karna

---

**Har lesson ke aakhir mein:** 2-3 sawal (quiz) + ek chhota kaam. Jawab Claude ko bhejo, wo check karega.
